# HCT-Student-GPA-Project

CDS 2413 - Student Performance and GPA Prediction Project

This project analyzes student academic performance using
Python and the Student Performance dataset.

Deliverable 1 includes data analysis, descriptive statistics,
visualizations, and statistical testing.

Deliverable 2 includes data preprocessing, regression,
classification, and clustering models.





## Project Objectives



The main objective of this project is to analyze student

performance and predict overall GPA using data science.



The project also compares machine learning models and

identifies student groups based on study habits and attendance.
